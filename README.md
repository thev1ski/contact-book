# Книга контактов

## Описание проекта

«Книга контактов» — это программа для хранения и управления контактами людей.

Она позволит пользователю сохранять номера телефонов, имена, электронные почты и другую информацию в одном месте.

Программа разрабатывается в рамках учебного проекта по дисциплине «Основы проектной деятельности».

## 1. Цель проекта

Создать простую и удобную программу, в которой можно хранить контакты, быстро находить нужных людей и изменять информацию о них.

Программа заменит обычную записную книжку и позволит не потерять важные контактные данные.

## 2. Основные возможности

Программа должна уметь:

- Добавлять новые контакты.
- Показывать список всех контактов.
- Искать контакты по имени или номеру телефона.
- Редактировать существующие контакты.
- Удалять ненужные контакты.
- Разделять контакты на группы (семья, друзья, работа, учёба).
- Сортировать контакты по имени.
- Показывать общее количество контактов.
- Сохранять контакты, чтобы они не пропадали после закрытия программы.

## 3. Информация о контакте

Для каждого контакта можно указать:

- Имя и фамилию.
- Номер телефона.
- Электронную почту.
- Группу контакта.
- Адрес.
- Дату рождения.
- Дополнительный комментарий.

Обязательными полями будут имя и номер телефона. Остальную информацию можно добавлять по желанию.

## 4. Как будет работать программа

При запуске программы пользователь увидит меню с доступными действиями.

Например:

1. Добавить контакт
2. Посмотреть все контакты
3. Найти контакт
4. Изменить контакт
5. Удалить контакт
6. Сохранить контакты
7. Выйти из программы

Пользователь выбирает нужный пункт и выполняет действие.

Если контакт не найден или пользователь ввёл неправильные данные, программа должна сообщить об этом.

Перед удалением контакта программа должна запрашивать подтверждение.

## 5. Технические требования

- Язык программирования — C++.
- Первая версия программы будет консольной.
- Интерфейс программы — на русском языке.
- Для хранения контактов будет использоваться файл.
- Программа должна сохранять данные между запусками.
- Код будет написан с использованием классов и объектно-ориентированного программирования (ООП).
- Программа должна работать на компьютере под Windows или Linux.
